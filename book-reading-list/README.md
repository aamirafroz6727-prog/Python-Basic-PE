## Features

- A web-based interface for managing a personal book reading list.
- Built using a Vite and TypeScript project setup.

## Getting Started

### Prerequisites

- Node.js and npm installed on your computer.
- Git, if you want to clone the repository using Git.

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project directory:

   ```bash
   cd book-reading-list
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.
